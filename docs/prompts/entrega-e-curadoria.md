# Consulta selecionada — Entrega e curadoria

## Finalidade

Comparar um deploy público de última hora com uma entrega local reproduzível e revisar a documentação pública do projeto.

## Contexto fornecido pelo desenvolvedor

- Escopo funcional obrigatório implementado.
- Backend, frontend, PostgreSQL, migrations, testes, Docker e CI disponíveis.
- Deploy público exigiria decisões adicionais sobre banco remoto, segredos, CORS e persistência de anexos.
- Notas extensas de trabalho poderiam desviar a avaliação do produto e das decisões técnicas.

## Solicitação

> Compare deploy público de última hora com uma entrega local reproduzível. Proponha a consolidação do Docker Compose fullstack, revise a documentação pública e reorganize o registro de uso de IA para destacar decisões e correções conduzidas pelo desenvolvedor. Não apresente testes como executados sem evidência real.

## Decisão do desenvolvedor

Foi priorizada a execução local fullstack, com scripts de validação, documentação consolidada e remoção das notas operacionais da árvore pública. O deploy permanece como evolução futura.
